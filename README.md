## 📂 Projects

### 01. OneCoreProcessor

A simple single-core CPU scheduling simulator using the **Round Robin** algorithm.

**Features:**
- Process management using `Queue<T>`
- Round Robin CPU scheduling
- Configurable time quantum
- Process completion tracking
- Total CPU execution time statistics

**Concepts:** C#, OOP, Queues, Scheduling Algorithms

**How to run:**

```bash
cd OneCoreProcessor
dotnet run
```
